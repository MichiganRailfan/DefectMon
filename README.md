# DefectMon (WIP)

DefectMon is a program that (as the name would suggest) records and transcribes railroad defect detectors via an SDR and monitors them.

## Use
Downloads are in releases.

First: Set something up that will record from an SDR to a `.wav` file in the `/watch_folder` directory whenever squelch (slightly above the noise floor) is broken.

Second: Double-click `run.bat`.
